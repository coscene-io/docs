# Cron 触发时间

Cron 语法用于安排自动化动作的运行时间。在刻行自动化中，Cron 只描述“什么时候触发”；具体执行哪个动作、动作使用哪些记录输入，由触发器的关联动作和记录条件决定。

## Cron 语法

Cron 调度使用由空格分隔的 5 个字段：

```
# ┌───────────── 分钟 (0 - 59)
# │ ┌───────────── 小时 (0 - 23)
# │ │ ┌───────────── 日期 (1 - 31)
# │ │ │ ┌───────────── 月份 (1 - 12)
# │ │ │ │ ┌───────────── 星期 (0 - 6)（星期日到星期六）
# │ │ │ │ │
# * * * * *
```

:::tip
创建定时触发器时需要同时选择时区。Cron 表达式中的小时和日期会按所选时区解释；例如 `0 9 * * 1` 配合 `Asia/Shanghai` 表示每周一北京时间 09:00 触发。
:::

在 cron 语法中，星号（\*）表示"每个"，因此以下 cron 字符串是有效的：

- 每小时在整点运行一次：`0 * * * *`
- 每天在午夜运行一次：`0 0 * * *`
- 每周在星期日午夜运行一次：`0 0 * * 0`
- 每月在第一天午夜运行一次：`0 0 1 * *`
- 每月在 22 日运行一次：`0 0 22 * *`
- 每年在 1 月 1 日午夜运行一次：`0 0 1 1 *`
- 每月在第 1 天和第 15 天的凌晨 3 点运行两次：`0 3 1,15 * *`

## Cron 示例

```
# 每天晚上 7:00 运行：
0 19 * * *

# 在 6 月 3 日每分钟运行：
* * 3 6 *

# 每周五 06:30 运行：
30 6 * * 5
```

## 常见注意事项

- 刻行自动化使用 5 段 Cron 表达式，不包含秒字段。
- Cron 表达式本身不包含要执行的命令；动作内容在触发器的「关联动作」中配置。
- 定时触发器可以结合记录条件使用，用于限制每次定时触发时匹配的记录范围。
